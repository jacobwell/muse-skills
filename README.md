# Muse skills

This repository contains the readable playbooks for Muse's 72 skills. Bundled
runtimes and binaries are intentionally not included here.

Every skill is documented in one `SKILL.md` file. This index links to all 72
playbooks and gives a quick TL;DR for each one.
